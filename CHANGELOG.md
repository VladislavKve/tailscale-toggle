# Changelog

## 2.1.0

- Added browser-based identity-provider sign-in.
- Added masked auth-key login through a private mode-`0600` runtime file.
- Added strict `login.tailscale.com` URL validation and secret redaction.
- Added local-profile capture and safe restore after interrupted account login.
- Added fail-closed controls during authentication and status refresh.
- Redesigned the GTK 4 / Libadwaita window and exit-node workflow.
- Added a separate GTK 3 Ayatana AppIndicator tray helper.
